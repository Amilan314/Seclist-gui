# SecLists 使用助手（本地图形界面）

一个 **纯本地 Tkinter 桌面窗口**，用来浏览、检索、理解和使用 SecLists 里的几千份字典，
并把「该用哪份字典 + 完整命令」直接摆到你面前，一键复制就能拿去执行。

- ✅ 原生窗口，**不监听任何端口、不启动 Web 服务、不联网**
- ✅ **不修改 SecLists 的任何原文件**；工具箱产生的新字典写到本目录 `data/output/`
- ✅ 只用 Python 标准库（Tkinter），不需要 pip 安装任何依赖

---

## 启动方式

**方式一：双击（推荐）**

```
seclists-gui\启动SecLists助手.cmd
```

**方式二：调试启动（保留控制台，能看到报错）**

```
seclists-gui\调试运行(显示日志).cmd
```

**方式三：命令行**

```bat
:: 无控制台窗口
"%LOCALAPPDATA%\Programs\Python\Python312\pythonw3.exe" SecListsAssistant.pyw

:: 直接打开某个标签页（0=引导 1=预览 2=搜索 3=工具箱 4=速查手册）
python SecListsAssistant.pyw --tab 3

:: 自检（不开窗口，跑完打印报告）
python SecListsAssistant.pyw --selftest
```

要求：Python 3.10+（本机为 3.12，自带 Tkinter）。

如果仓库不在本工具的上一级目录，可用环境变量指定：

```bat
set SECLISTS_ROOT=D:\Tools\SecLists
```

## 引导场景覆盖范围

- **快速上手**：第一次用 SecLists，5 分钟上手
- **内容与接口发现**：Web 目录/文件爆破、敏感文件与备份泄露、API 端点与参数名枚举、403/访问控制绕过、自建与加工字典
- **资产侦察**：子域名枚举、端口/服务/SNMP
- **口令与账户**：用户名枚举、口令爆破与喷洒、默认凭据、哈希离线破解、WiFi/WPA
- **注入与载荷**：XSS、SQLi、LFI、命令注入/SSTI/XXE、数字枚举（验证码/ID 遍历）
- **特殊场景**：文件上传测试（Zip 炸弹/畸形文件名/EICAR）、WebShell、AI/LLM 应用测试、源码审计与敏感信息扫描、杂项清单妙用

每个场景里的字典路径、命令都指向**本仓库真实存在**的文件（`--selftest` 会逐条校验 128 个路径）。

## 常见问题

**启动没反应？**
用 `调试运行(显示日志).cmd` 启动，看控制台报错，或查看 `data\error.log`。

**显示「没有找到 Python 3」？**
安装 Python 3.10+ 并勾选 *Add python.exe to PATH*，或用 `set SECLISTS_ROOT=...` 配合绝对路径直接调用 `pythonw.exe`。

**某份字典显示「未找到」？**
该仓库副本可能被裁剪过（本工具会在引导页用红字标出），可在左侧导航按关键字搜索同类字典替代。

**行数统计很慢？**
首次统计会把结果缓存进 `data\linecounts.json`（按文件大小+修改时间失效），之后是瞬时的。删除该文件即可重建。

**大字典去重会不会吃内存？**
会。去重需要把已见条目放在内存里，200MB 以上的字典建议在 Linux 端用 `sort -u`。工具箱在选择大文件时会提示。

## 开发自检

改动代码后跑一次自检，它会校验索引、128 个场景字典路径、全部场景渲染、
五个标签页的实际排版尺寸、预览/行数统计/内容搜索/工具箱（含完整后台线程链路）：

```bat
python SecListsAssistant.pyw --selftest
```

想进一步确认界面外观（当前环境无图像输入时）：

```bat
powershell -ExecutionPolicy Bypass -File devtools\capture_tabs.ps1
python devtools\analyze_shot.py
```
